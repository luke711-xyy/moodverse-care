MOSIC 桌面驾驶舱

在 Mac 上进入与网页版相同的驾驶舱。点亮观察窗里的副驾，可以用自己的模型点歌、对讲，再去拜访选过同一首歌的星球。

下载 Mac 应用 ↓ 下载开源源码 ↓
v0.1.3 · Apple Silicon · ZIP · MIT

首次打开

解压 ZIP，将 MOSIC Copilot 移到“应用程序”。此版本尚未通过 Apple 公证。如果 macOS 拦截首次打开，可核对下载来源后按 Apple 的步骤在“隐私与安全性”中确认。查看 Apple 说明

选择模型

打开应用的本机连接设置，选择 Ollama、LM Studio、自己的 API Key 或 ChatGPT 授权。回到观察窗，在副驾设置里选择桌面连接。

本机对讲

按住「按住说话」时，支持本机普通话识别的 Mac 会边听边把文字写进输入框。松开后可以改字，点「发送」才会把消息交给所选模型。也可以直接打字。

源码与 Claude Code

桌面程序与源码可免费下载。源码包内的 src/mcp.mjs 可以注册为 Claude Code 的 stdio MCP 工具，用来查歌和起草介绍。主动配对设备后，还能查找真实的同歌星球。安装和配对步骤见源码包内的 README。
